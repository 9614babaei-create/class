# حضور و غیاب کلاسی — نسخه ۳
Minimum SDK: Android 8 / API 26

امکانات:
- تقویم و نمایش تاریخ شمسی
- ثبت روزانه حضور/غیبت/تأخیر/موجه
- گزارش ماهانه
- خروجی Excel واقعی (.xlsx)
- پشتیبان‌گیری JSON و اشتراک‌گذاری فایل
- تنظیم نام مدرسه و معلم
- جست‌وجو/گزارش و مدیریت کلاس و دانش‌آموز
- کاملاً آفلاین

نکته: برای بازیابی پشتیبان، در نسخه بعدی می‌توانیم Import/Restore با انتخاب فایل را هم به رابط کاربری اضافه کنیم.
